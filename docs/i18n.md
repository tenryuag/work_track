# 🌐 Internacionalización (i18n)

## Visión General

WorkTrack soporta múltiples idiomas con un sistema de internacionalización personalizado basado en React Context.

### Idiomas Soportados

| Código | Idioma | Estado |
|--------|--------|--------|
| `ja` | 日本語 (Japonés) | ✅ Completo |
| `en` | English (Inglés) | ✅ Completo |

## Arquitectura del Sistema

```
src/
├── i18n/
│   └── translations.ts          # Todas las traducciones (ja + en)
├── context/
│   └── LanguageContext.tsx       # Context global + función t()
└── utils/
    └── translationHelpers.ts    # Helpers para valores dinámicos
```

## Uso Básico

### En Componentes

```typescript
import { useLanguage } from '../context/LanguageContext';

const MyComponent = () => {
  const { t, language, setLanguage } = useLanguage();

  return (
    <div>
      <h1>{t('appName')}</h1>
      <p>{t('email')}</p>
      {/* Con parámetros */}
      <p>{t('totalOrders', { count: 5 })}</p>
    </div>
  );
};
```

### API del Hook `useLanguage`

| Propiedad | Tipo | Descripción |
|-----------|------|-------------|
| `t(key, params?)` | `Function` | Función de traducción |
| `language` | `'ja' \| 'en'` | Idioma actual |
| `setLanguage(lang)` | `Function` | Cambiar idioma |

### Para Valores Dinámicos (Prioridades, Estados)

```typescript
import { getPriorityLabel, getStatusLabel } from '../utils/translationHelpers';

const label = getPriorityLabel(order.priority, t); // "Alta" / "高"
const status = getStatusLabel(order.status, t);     // "En proceso" / "進行中"
```

## Agregar Nuevas Traducciones

### Paso 1: Agregar clave en `translations.ts`

```typescript
export const translations = {
  ja: {
    // ...existentes
    myNewKey: '新しいテキスト',
  },
  en: {
    // ...existentes
    myNewKey: 'New Text',
  },
};
```

### Paso 2: Usar en el componente

```typescript
<p>{t('myNewKey')}</p>
```

El tipo `TranslationKey` se genera automáticamente, por lo que habrá autocompletado en TypeScript.

## Agregar un Nuevo Idioma

### Paso 1: Agregar traducciones

```typescript
// En translations.ts
export const translations = {
  ja: { /* ... */ },
  en: { /* ... */ },
  es: {  // Nuevo
    appName: 'WorkTrack',
    login: 'Iniciar sesión',
    email: 'Correo electrónico',
    // ...todas las claves
  },
};
```

### Paso 2: Actualizar el tipo Language

```typescript
export type Language = 'ja' | 'en' | 'es';
```

### Paso 3: Actualizar selectores de idioma

En `Layout.tsx` y `Login.tsx`, agregar la opción para el nuevo idioma.

## Características

- ✅ Cambio de idioma en tiempo real sin recargar
- ✅ Persistencia del idioma en `localStorage`
- ✅ Selector de idioma en el header y pantalla de login
- ✅ Soporte para parámetros en traducciones (`{count}`, etc.)
- ✅ Autocompletado TypeScript para claves de traducción
